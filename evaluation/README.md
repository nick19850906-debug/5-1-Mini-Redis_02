## 먼저 그림 하나로 이해하기 (우리 프로그램 전체 구조)

키 `"user:1"` 하나를 저장하면, 우리 프로그램([mini_redis/mini_redis.py](../mini_redis/mini_redis.py))은 역할이 다른 **3가지 도구**를 같이 씁니다.

1. **해시맵 (`hashmap.py`) — "이름표 사물함"**  
   `user:1`을 검색하면 **값(`"Alice"`), 줄 서 있는 자리표(`lru_node`), 유통기한(`expire_at`)** 을 묶은 상자(`Entry`)를 바로 꺼내 줍니다.
2. **이중 연결 리스트 (`doubly_linked_list.py`) — "최근 쓴 순서 줄"**  
   방금 쓴 키는 **맨 앞(`head`)**, 제일 오래 안 쓴 키는 **맨 뒤(`tail`)** 에 세워 둡니다. 공간이 꽉 차면 **맨 뒤(`tail`)** 부터 치웁니다.
3. **최소 힙 (`min_heap.py`) — "유통기한 알림판"**  
   만료 시간(`EXPIRE`)이 있는 키들 중 **가장 빨리 상할 키 하나**를 맨 꼭대기에 올려 두고 바로 확인합니다.

> **핵심**: 지울 일이 생기면 항상 `delete_entry(키)` 함수 한 곳만 거쳐서 **사물함 + 줄 + 메모리 숫자**를 동시에 뺍니다. 그래서 상태가 꼬이지 않습니다!
